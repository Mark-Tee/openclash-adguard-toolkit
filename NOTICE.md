# Third-Party Sources

This repository contains original scripts and sanitized documentation informed
by the following public projects:

- OpenClash: https://github.com/vernesong/OpenClash (MIT)
- AdGuard Home: https://github.com/AdguardTeam/AdGuardHome (GPL-3.0)
- AdGuard HostlistsRegistry: https://github.com/AdguardTeam/HostlistsRegistry (GPL-3.0)
- MetaCubeXD: https://github.com/MetaCubeX/metacubexd (MIT)
- Aethersailor Custom_OpenClash_Rules: https://github.com/Aethersailor/Custom_OpenClash_Rules (CC-BY-SA-4.0)
- anti-AD: https://github.com/privacy-protection-tools/anti-AD (MIT)

No upstream source code is vendored in this repository. Domain lists are
minimal functional data and are documented with their source links.
Mihomo behavior in this repository is verified against the configuration
template bundled with the installed OpenClash version.
